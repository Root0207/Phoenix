# 🍽️ Table Reservation System

## 📌 Project Overview

The **Table Reservation System** is designed to help a hotel efficiently manage table bookings and reduce customer waiting time. This system allows customers to view available tables, reserve them based on seating requirements, and receive booking notifications. It also helps the hotel staff manage table availability dynamically.

---

## 🎯 Objectives

* To minimize customer waiting time in the hotel
* To automate table allocation based on seating requirements
* To maintain real-time status of tables (Available / Occupied)
* To provide booking notifications to both customers and management
* To ensure smooth handling of reservations and billing

---

## ⚙️ Features

### 🔹 1. Table Availability Display

* Displays the total number of tables in the hotel
* Shows number of seats available per table
* Provides real-time availability status

---

### 🔹 2. Automatic Table Reservation

* Customers enter the number of seats required
* System automatically assigns the most suitable table
* Prevents overbooking and inefficient allocation

---

### 🔹 3. Booking Notifications

* Confirmation message sent to the customer after booking
* Notification sent to the hotel manager
* Helps in better coordination and management

---

### 🔹 4. Table Status Management

* Tables are marked as **Occupied** once reserved
* After bill payment, status changes to **Available**
* Ensures accurate tracking of table usage

---

### 🔹 5. Dynamic Availability Refresh

* System periodically updates table status
* Displays latest availability to users
* Avoids confusion and outdated information

---

## 🏗️ System Modules

### 1. Table Management Module

* Stores table details (table number, seating capacity)
* Tracks current status of each table

### 2. Reservation Module

* Accepts user input for seat requirements
* Allocates appropriate table automatically

### 3. Notification Module

* Sends booking confirmation messages
* Alerts hotel management

### 4. Billing Module

* Handles payment process
* Updates table status after payment

### 5. Display Module

* Shows updated table availability
* Refreshes data periodically

---

## 🧠 Working Principle

1. Customer enters required number of seats
2. System searches for suitable available table
3. Table is reserved and marked as occupied
4. Notifications are sent
5. After billing, table is marked available
6. System refreshes availability continuously
